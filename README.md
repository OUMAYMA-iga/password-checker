# Password Strength Checker 🔐

Hey! This is one of my first projects combining web dev and cybersecurity.
The idea came to me because I realized most people have no idea how weak 
their passwords are — so I built something to help with that.

## What it does
You type a password and it tells you in real time if it's weak, fair, 
good or strong. It also gives you tips on how to improve it and detects 
common passwords like "123456" or "password" that you should never use.

## Why I built this
I'm in Master 1 Informatique specializing in Dev & Cybersecurity and I 
wanted to build something that actually makes sense in real life — 
not just a tutorial project. Password security is a real problem and 
this is my small contribution to raise awareness about it.
